## Privacy Policy

**Last updated: 11/14/2025**

### 1. Introduction

Smart KB Helper is designed with a privacy-first approach. This policy explains how the extension handles data when helping users capture webpage content for upload to the Smart Platform.

### 2. What the Extension Does

The extension captures content from the webpage currently open in the user's active tab. It works only when the user manually activates it and does not run, track, or monitor activity in the background.

### 3. Information the Extension Accesses

When activated by the user, the extension may:

- Read visible content on the active page to upload it to Smart
- Rely on the browser's existing login session to access pages the user already has permission to view

The extension does not collect personal data, browsing history, analytics, credentials, cookies, or authentication tokens. It does not store or reuse any accessed information.

### 4. How Collected Information Is Used

Accessed content is used only to complete the specific action the user triggers, such as:

- Extracting page content
- Sending it to the Smart Platform
- Determining whether the page supports automatic or manual updates

No data is used for analytics, advertising, profiling, or shared with third parties.

### 5. Data Storage

The extension does not store any captured content or authentication information locally or on external servers.

All uploaded data is handled under Smart Platform policies.

### 6. Data Security

Data transmitted from the extension to the Smart platform is sent over secure channels. Because the extension does not store data or long-term credentials, exposure risk is minimized.

### 7. User Control

Users control all actions, including:

- When the extension runs
- Which pages are captured
- Whether a page is marked as requiring login
- Enabling, disabling, or uninstalling the extension

The extension performs no actions without explicit user initiation.

### 8. Changes to This Policy

This Privacy Policy may be updated from time to time. If changes are made, the effective date at the top of this page will be updated. Continuing to use the extension after updates indicates acceptance of the revised policy.

### 9. Contact Us

For questions about this Privacy Policy or the extension, please contact: Smart Platform Assistant (Seatalk bot).
